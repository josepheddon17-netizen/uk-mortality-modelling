# UK Mortality and Longevity Modelling

## Project Overview

This project investigates mortality and longevity in the United Kingdom using computational and statistical methods. It aims to explore historical mortality trends, construct life tables, fit parametric mortality models and investigate applications in actuarial mathematics.

The project is developed entirely in MATLAB, with an emphasis on numerical methods, statistical modelling, data visualisation and actuarial interpretation.

## Objectives

- Acquire and process historical UK mortality data.
- Calculate age-specific mortality rates.
- Investigate differences in mortality between males and females.
- Construct life tables and estimate life expectancy.
- Fit and evaluate Gompertz and Gompertz–Makeham mortality models.
- Investigate mortality improvements and potential forecasting methods.
- Apply mortality models to annuity valuation.
- Evaluate model assumptions, accuracy and uncertainty.
